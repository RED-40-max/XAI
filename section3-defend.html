Defend the Agent

To use agent systems safely, it is not enough to know structure. You also need to understand failure modes in practice. Move with arrow keys and press space to shoot; each bug maps to a real AI failure pattern.

Failure Modes You Are Defending Against

Prompt Injection: external input manipulates objectives and overrides original intent.

Internal Agent Dysfunction: the system drifts or hallucinates reflection, then reinforces errors.

Autonomy Overreach: the agent takes tool actions beyond intended limits, creating real consequences.

What Users Can Do

Limit access: avoid giving full permissions to banking, email, and sensitive files.

Stay in the loop: review outputs before acting on money, identity, or communication steps.

Know when to stop: if behavior drifts, pause, reset, and re-check goals instead of blindly iterating.
